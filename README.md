# Automated Statutory Legal Notice Drafter (NI Act Sec 138)

A lightweight Python automation tool that converts structured case records into clean, legally compliant demand notices within seconds—eliminating repetitive drafting time and human error.

---

### Features
* Instant Section 138 NI Act draft generation
* Automatic date stamping and liability statement mapping
* Generates clean `.txt` output ready for direct print or firm letterheads

---

### Quick Start
```bash
python notice_generator.py
